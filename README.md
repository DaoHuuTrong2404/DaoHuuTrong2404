## Learning and contributing

My current focus is reproducible local examples, clearer documentation and tests for observable behavior. The agent workspace is an educational prototype: it does not connect to an LLM, operate a computer or run distributed workers.

Issues with concrete reproduction steps and focused contributions are welcome. See each repository's README for installation, limitations and license terms.
